# グラスヒット＆ブロー — Glass Hit & Blow

Meta Ray-Ban Display 用の**数当て推理ゲーム「ヒット＆ブロー」**。かくされた重複なしの数字（3けた／4けた）を推理して当てる。数字も位置も合えば**ヒット ●**、数字だけ合えば**ブロー ○**。D-pad の↑↓で数字を回し、←→でけたを移動、「決定」をタップするだけ。**のこり候補が何通りあるか**と、**0〜9のどれがかならず入る／入らないか**を毎回自動で計算して見せてくれるので、推理の手ごたえが目の前でわかる。依存ライブラリなし・オフライン動作。

- **ライブURL**: https://glass-hitblow.vercel.app
- **画面**: 600×600 / 加算式ディスプレイ対応（背景 #000000 = 透明）
- **依存ライブラリなし**（Vanilla JS / DOM / 静的サイト）

## 特徴

- **D-pad だけで数字入力** — ↑↓で数字を回す（ほかのけたで使っている数字は自動でとばすので、重複した数字は入らない）。タップで次のけたへ、右はしの「決定」で判定
- **●○で結果が並ぶ** — 最新6回分の予想と、ヒット（●）・ブロー（○）が一覧で残る
- **のこり候補の数** — これまでの結果と矛盾しない答えが何通り残っているかを毎回表示（4けたなら 5040 通りからスタート）
- **0〜9 の自動メモ** — 候補すべてに含まれる数字は緑、どの候補にも含まれない数字は取り消し線。紙のメモ不要
- **3けた／4けた** — 3けた（720通り）はかんたん、4けた（5040通り）はふつう。けた数ごとのベスト記録とクリア回数を保存
- **とちゅうでメニュー** — 左はしの「≡」から、ゲームにもどる／あきらめて答えを見る／タイトルへ

## 操作方法

| 画面 | 操作 |
|------|------|
| タイトル | ↑↓でえらんでタップ。「けた数」の行は←→（またはタップ）で3けた／4けたを切り替え |
| ゲーム | ←→でけた・≡・決定を移動、↑↓で数字を変える、タップで次のけたへ／決定／メニュー |
| メニュー・結果 | ↑↓でえらんでタップ（「← ゲームにもどる」「▶ もう一度」「タイトルへ」） |
| つかいかた | タップで「← タイトルにもどる」 |
| PC確認用 | Escape でひとつ前の画面へ、数字のマスをクリックで選択（グラスの戻るジェスチャーは使用不可のため補助のみ） |

`?auto=1` を付けると自動プレイ（候補を最も絞り込める予想を選ぶソルバーが操作する。デモ録画用で記録は保存しない）。`?seed=N` で答えを固定できます。

## グラスへの登録

`qr-publish.png` の QR コードをスマホでスキャンすると Meta AI アプリが開き、自動で Web アプリとして登録されます。

ディープリンク:
```
fb-viewapp://web_app_deep_link?appName=%E3%82%B0%E3%83%A9%E3%82%B9%E3%83%92%E3%83%83%E3%83%88%EF%BC%86%E3%83%96%E3%83%AD%E3%83%BC&appUrl=https%3A%2F%2Fglass-hitblow.vercel.app
```

手動登録の場合: Meta AI アプリ → デバイス → ディスプレイグラス設定 → アプリ接続 → Web アプリ → 「Web アプリを追加」で名前 `グラスヒット＆ブロー`、URL `https://glass-hitblow.vercel.app` を入力。
